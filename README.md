### 概要
　メモWEBアプリケーションは、開発言語を一から学習するために、アジャイル開発の形式で作成しました。
　Reactを初めて触り、機能や技術などでファイル分けをせず、同じファイルに記載しております。
　自己申告で期限を設けておりましたので、テストが不十分なことと、当初予定していた実装までできず、一部コメントアウトにしております。
　メモに必要な最低限の機能として、新規登録、編集更新、削除、一覧取得を実装しました。

### マイグレーション（Alembic）を使用した経緯
　はじめは、PythonとReactのみのWEBアプリケーションを開発しておりました。
　ソースコードを提出することになり、前職にてPythonで実装した高度なSQL作成は困難だったため、実際にアジャイル開発形式で実装をすることにしました。フロントエンドで改修が入り、DBをはじめから作り直すという工程で開発しました。


### DB設計
テーブル名：memos
```
カラム
No | 物理名　　　| 論理名　　| データ型　 | 長さ | NOT NULL | 初期値
1. | id         | MEMO_ID  | INTEGER   | -    | NOT NULL |
2. | title      | タイトル　| STRING    | 100  | NOT NULL |
3. | content    | 内容　　　| STRING    | 255  |          |
4. | status     | 区分　　　| STRING    | 100  |          | 未完了
5. | created_at | 作成日　　| TIMESTAMP |      |          |
6. | updated_at | 更新日　　| TIMESTAMP |      |          |
```
＊フロント側でエラーが設定されているため、業務ではnull=Falseの設定をDBでも行うところですが、今回はReactの学習のためにnull=Trueにしております。


### APIの設計（Python、React）
```
No | 操作　　　　　　　　| メソッド　| URL            | データ形式 | Key
1. | 仮想環境へアクセス　| GET      | /              | JSON      | "Welcome to Memo API"
2. | メモ一覧取得　　　　| GET      | /memos/        | JSON      | DBのレコード情報
3. | メモを新規作成　　　| POST     | /memos/        | JSON      | title, content, status
4. | メモを更新　　　　　| put      | /mwmos/memo_id | JSON      | title, content, status
5. | メモを削除　　　　　| DELETE   | /mwmos/memo_id | JSON      | memo_idのレコード
```
```
No | エラータイプ | メソッド　| メッセージ
1. | 404         | PUT      | Memo not found
2. | 404         | DELETE   | Memo not found
```
＊メモを更新して、updated_atの値が登録されます。
＊Keyは、schemas.pyに記載しました。

### フロントの設計（React）
```
No | 操作　　　　　 | メソッド　| Key　　　　　　　　　　　| 備考
1. | メモを新規登録 | POST     | title, content, status | 一覧に表示され、作成日が表示される
2. | 一覧のメモ更新 | PUT      | title, content, status | 作成日は変わらず、更新日が表示される
3. | 一覧のメモ削除 | DELETE   | memo_id                | memo_idのメモが消える
```
```
No | 操作　　　　　　　　| メソッド　| エラー条件　　　　　　　| エラー内容
1. | メモ一覧取得　　　　| GET      | 一覧を取得できない場合　| "Fetch error:"
2. | メモを新規作成　　　| POST     | titleやcontentが未入力 | "タイトルと内容を入力してください"
3. | メモを新規作成　　　| POST     | 新規登録失敗　　　　　　| "登録に失敗しました"
4. | メモを新規作成　　　| POST     | 非同期処理の失敗　　　　| "追加エラー"
5. | メモを更新　　　　　| put      | titleやcontentが未入力 | "タイトルと内容を入力してください"
6. | メモを更新　　　　　| put      | 非同期処理の失敗　　　　|
7. | メモを削除　　　　　| DELETE   | 削除失敗　　　　　　　  |
```

### 反省
　フロントエンドでは、技術別か、または機能別にソースコードをファイル分けして、表記が揃っていない部分を修正し、引き続き実装を進めたいと思います。
　バックエンドでは、Temporary Redirectの警告が出ていた為、ソースコードを見直し、フロントエンドの機能と合わせて修正したいと思います。
　上記の対応が終わったら、テストコードやテスト項目書を作成し、テストを実施したいと考えております。
